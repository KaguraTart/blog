## 先讲个故事

小林下周三有个面试。他准备了很久，但心里还是没底，于是跑来问：

> "这次面试能过吗？"

传统六爻的做法是这样的：

1. 拿出三枚铜钱，静下心来，把问题在心里说清楚；
2. 摇六次，每次记下铜钱的正反面；
3. 根据六次结果画出一个卦；
4. 按固定规则给这个卦"装上"五行、六亲、六神、世应；
5. 找到代表"工作"的那个爻（用神），看它旺不旺、有没有被生扶或克害；
6. 给出一个判断：希望大不大、大概什么时候有消息、要注意什么。

这套流程听起来神秘，其实可以拆成三件很朴素的事：

- **用随机方式得到一个卦**（起卦）；
- **按固定规则把卦"装修"成一张信息表**（装卦）；
- **按五行生克去读这张表**（断卦）。

这一章，我们就把这三件事说清楚。

---

## 1.1 一句话定义

> **六爻，是以《周易》六十四卦为符号系统，以五行生克为规则，通过起卦、装卦、断卦来推断某件事发展趋势的传统占断方法。**

拆开看，有三个关键词：

| 关键词 | 含义                   | 类比                     |
| ------ | ---------------------- | ------------------------ |
| 符号   | 六十四卦，每卦六层阴阳 | 一套只有 64 个词的字母表 |
| 规则   | 五行生克、旺衰、冲合   | 一套语法                 |
| 操作   | 起卦 → 装卦 → 断卦     | 写一篇文章的流程         |

六爻不要求你相信"铜钱有灵"。它更像一套**符号运算系统**：输入是一个随机得到的卦，中间是一堆确定的规则，输出是一段可解释的判断。

---

## 1.2 六爻的三层结构

| 层次       | 做什么                         | 随机还是确定 | 难度 |
| ---------- | ------------------------------ | ------------ | ---- |
| **起卦层** | 摇六次铜钱，得到本卦与动爻     | 随机         | 低   |
| **装卦层** | 纳甲、定六亲、安六神、排世应   | 完全确定     | 中   |
| **断卦层** | 取用神、看旺衰、论生克、下判断 | 规则 + 经验  | 高   |

这个结构很重要，因为它解释了六爻为什么"既客观又主观"：

- **装卦层是客观的**：同一个卦、同一天，任何人装出来的纳甲、六亲、世应都应该一样；
- **断卦层是主观的**：先看什么、后看什么、哪个信号更重要，不同人有不同的权重分配。

所以，学六爻的第一步不是学"怎么断"，而是学"怎么装"——把确定的部分做对，才有资格谈不确定的部分。

## 1.3 六爻的来历（极简版）

| 时期     | 发生了什么                       | 对今天的意义                             |
| -------- | -------------------------------- | ---------------------------------------- |
| 先秦     | 《周易》用蓍草成卦，有卦辞、爻辞 | 提供了六十四卦的符号系统                 |
| 西汉     | 京房创纳甲、八宫、六亲、世应     | 六爻的"元数据层"诞生                     |
| 唐宋之间 | 《火珠林》推行"以钱代蓍"         | 三枚铜钱摇六次，成为主流起卦法           |
| 明清     | 《增删卜易》《卜筮正宗》等成熟   | 用神、月建日辰、旺衰、应期的断卦体系定型 |

这里要特别澄清一个常见误解：

> **六爻不等于"用《周易》卦辞爻辞算命"。**

六爻借用《周易》的卦象符号，但断卦主要看的是**五行、六亲、旺衰、生克**，而不是去翻卦辞。也就是说，它是一套在《周易》符号系统上发展出来的"纳甲筮法"，和先秦的蓍草占筮已经不是同一套操作。

---

## 1.4 六爻不是梅花易数，也不是八字

初学者最容易把这几样混在一起。一张表说清楚：

|               | 六爻                   | 梅花易数         | 八字                 |
| ------------- | ---------------------- | ---------------- | -------------------- |
| 起卦/起盘方式 | 三枚铜钱摇六次         | 时间、数字、外应 | 出生年月日时         |
| 核心工具      | 六亲、五行、旺衰、世应 | 卦象、体用、外应 | 天干地支、十神、大运 |
| 擅长          | 具体事项的短期趋势     | 快速取象、灵活   | 一生格局与长期趋势   |
| 学习特点      | 规则多，但系统         | 入门快，精通难   | 体系庞大，周期长     |

**本讲义只讲六爻（纳甲筮法）**，不涉及梅花易数和八字。

---

## 1.5 六爻能做什么，不能做什么

### 能做的

- **把模糊问题结构化**：逼你把"我最近好迷茫"变成"我这个月换工作是否合适"；
- **提供多角度**：用神、世应、月日、动变，各自代表不同视角；
- **辅助复盘**：记录卦象与后续事实，训练自己的判断力；
- **文化学习**：理解古人如何用符号系统处理不确定性。

### 不能做的

- **精确预测未来**：它给的是趋势与概率感，不是确定答案；
- **替代专业意见**：医疗、法律、投资、心理问题，请找专业人士；
- **保证准确率**：同一卦不同人解，结论可能完全不同；
- **替别人做决定**：卦象是参考，选择权永远在人手里。

> **蛋挞提醒**：如果一个人告诉你"这个卦百分之百说明你一定会……"，无论他多有名，这句话本身就不符合六爻的传统——六爻讲的是旺衰、趋势、应期，不是铁口直断。
